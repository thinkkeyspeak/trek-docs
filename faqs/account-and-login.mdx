## Logging In

<AccordionGroup>
  <Accordion title="Does Trek support Single Sign-On (SSO)?">
    Yes! We have both Google and Microsoft Single Sign-On. No matter what LMS/SIS you sync with, you will be able to SSO with Google or Microsoft.
  </Accordion>

  <Accordion title="Why can't I log in with Google?">
    In Google Workspace for Education, students are blocked from third-party apps until the exact OAuth client used for Trek’s Google login is configured as Trusted for their organizational unit.

    Here's how to fix it:

    1. Go to Google Admin console → **Security → Access and data control → API controls → Manage Third-Party Access**.
    2. Configure by **OAuth Client ID**. This is Trek's: [123576902546-m2fl21553v6hvlifkh1t10slg4d2fsht.apps.googleusercontent.com](http://123576902546-m2fl21553v6hvlifkh1t10slg4d2fsht.apps.googleusercontent.com)
    3. Set **Trusted**, and apply to **student OUs** (or the whole organization).
  </Accordion>

  <Accordion title="Why can't I log in with Microsoft?">
    Some schools’ Microsoft 365 (Entra ID) setups block third-party apps until an admin approves them. If your school approved the Trek Classic app, you also need to approve the **Trek Learning** app. It’s a separate app with its own ID.

    Users usually see a Microsoft message like “Need admin approval” or “Approval required,” or an error code starting with **AADSTS** (for example AADSTS65001, AADSTS90094 or AADSTS50105).

    Here’s how to fix it (a Microsoft 365 admin needs to do this):

    1. Go to the **Microsoft Entra admin center** → **Identity** → **Applications** → **Enterprise applications**.
    2. Search for Trek’s Application (client) ID: `1975d47a-bf7b-474f-b42d-51136cb17d74`
    3. Open the app → **Permissions** → **Grant admin consent for [your school]**, and accept.
    4. If your school requires users to be assigned to apps, go to **Users and groups** → **Add user/group** and add your staff (and students, if they’ll use Trek).

    If the app doesn’t appear in step 2, sign in to Trek once with your Microsoft admin account and choose **Consent on behalf of your organization** when Microsoft asks.

    **Still can’t sign in?** Make sure you’re using the **Sign in with Microsoft** button. Accounts set up for Microsoft sign-in don’t have a Trek password. If it still fails, send us a screenshot of the error, including the AADSTS code.
  </Accordion>

  <Accordion title="Can I resend login emails?">
    Yes! As a school admin, you can resend login emails. Navigate to Users > Pencil icon next to the student's name > Reset password.
  </Accordion>

  <Accordion title="How do I reset student passwords?">
    See this video [tutorial](https://www.loom.com/share/d4fed629365c4e989471342cbbf6e1d5) if one or all students need passwords reset.
  </Accordion>

  <Accordion title="Our students don't have email addresses. Can they still get Trek Learning accounts?">
    Inform your Partner Success Specialist, and they will provide an alternative login solution so your students can access Trek Learning.
  </Accordion>
</AccordionGroup>

## Roles & Access

<AccordionGroup>
  <Accordion title="What roles are available in my Trek Learning account?">
    Trek Learning offers several user roles. Each includes specific permissions and access levels to ensure the platform is used effectively and securely within your school or district.

    - School Admin
    - IT Admin
    - Teacher
    - Student
  </Accordion>

  <Accordion title="How do I add an admin?">
    Users with School Admin access can manage admin permissions in the Admin Dashboard. To update a user's role, navigate to Admin in the left-hand menu, select All Users, then click Edit User next to the appropriate name. From there, update the user's role under User Role and save your changes.
  </Accordion>

  <Accordion title="How can I increase the number of user accounts (licenses) for my school?">
    To request additional user accounts or licenses, please contact your Partner Success Manager. They'll guide you through the process and help adjust your plan based on your school or district's needs.
  </Accordion>

  <Accordion title="Is my data secure?">
    Absolutely! We're COPPA and FERPA compliant. Everything you put into Trek is yours and not ours. We do not use it to train any other models and any agreements we have with providers say they will not use it to train their models. We don't sell data and we don't use anything you upload to train other models. We're pretty tight on all data privacy.
  </Accordion>
</AccordionGroup>
