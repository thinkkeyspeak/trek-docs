---
title: "Project-Based Learning Resources"
---

Project-based learning asks a lot of teachers up front — coming up with a strong project idea, scoping it realistically, and building the lesson plans and rubrics to support it. TrekAi is built to help with exactly that: TrekAi includes a Project-Based Learning tool that helps teachers generate project ideas, refine project scope, and create lesson plans and rubrics, supporting multidisciplinary instruction and real-world learning experiences. 

In practice, that means less time spent staring at a blank page before a PBL unit even gets off the ground, and more time actually running it with students.
