Trek includes a **Project-Based Learning (PBL) tool** that helps teachers plan and run real-world, multidisciplinary projects.

## What the PBL tool supports

- **Generate project ideas** and refine project scope
- **Create lesson plans** aligned to your goals
- **Build rubrics** for student work

Use it when you want students working on extended inquiry—not just single-session assignments.
