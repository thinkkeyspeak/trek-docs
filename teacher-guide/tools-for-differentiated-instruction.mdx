Trek supports differentiated instruction through several teacher-facing tools.

## Key tools

| Tool | Use it to |
| --- | --- |
| **Essential Question Generator** | Prompt higher-order thinking |
| **Lesson Plan Customization** | Adapt plans for different groups or goals |
| **Quiz Generator** | Build quizzes with Depth of Knowledge (DOK) levels |
| **AI-resistant assignment tools** | Design tasks that emphasize original student thinking |

Combine these tools when students need different entry points or levels of challenge in the same unit.
