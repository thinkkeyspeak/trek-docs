Trek does not ship AP-specific curriculum, but it includes tools AP students can use for practice and review.

## Tools that support AP students

| Tool | Use for AP prep |
| --- | --- |
| **Quiz Generator** | AP-style practice questions |
| **Essential Question Generator** | Higher-level analysis and writing prompts |
| **Tutor Mode** | Study, review, and clarification |

## Tips for teachers

- Frame Trek assignments around your existing AP units and rubrics.
- Use Quiz Generator for low-stakes practice before high-stakes exams.
- Review student chats when you need visibility into how they are using Trek for review.
