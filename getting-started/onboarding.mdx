## Roster Data Options

### Option 1: LMS/SIS Integration via Edlink _(recommended for \\\> 50 users)_

**How does it work?** See list of compatible platforms \[here\]([https://docs.google.com/document/d/1PUp3bgsrI7pahoV\_Yy90u0bswgdm1cL3gT7wfRNKnQQ/edit?usp=sharing](https://docs.google.com/document/d/1PUp3bgsrI7pahoV_Yy90u0bswgdm1cL3gT7wfRNKnQQ/edit?usp=sharing)).

- **Source of truth:** LMS/SIS is the system of record — TrekAi mirrors it. EdLink syncs automatically every few hours depending on LMS/SIS.
- **Unique emails required:** Every teacher and student needs a unique email.
- **One connection per school:** Only one active Edlink connection per school.
- **Sharing permissions:** Schools control which data is shared. Please **only** share user information for those that will be using TrekAi. Sharing additional users could cause delays.

👉 \[Request to integrate with EdLink\]([https://ed.link/integrate/340bc574-3393-479a-985f-1074d8e13abd](https://ed.link/integrate/340bc574-3393-479a-985f-1074d8e13abd))

#### Troubleshooting & Integration FAQ

| Issue | Resolution |

| :-- | :-- |

| **Missing emails** | Ensure all students have unique emails in LMS/SIS. |

| **Duplicate student IDs** | Resolve duplicates in source system before sync. |

| **Teachers not assigned** | Assign teachers in LMS prior to integration. |

| **Courses not published** | Publish all courses in Canvas or Google Classroom. |

| **Archived users** | Only active students sync; archived courses are excluded. |

Manual re-syncs can be requested with \[EdLink Support\]([https://ed.link/support](https://ed.link/support)).
